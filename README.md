# Riverdale Subtitle Text Analysis

## Overview

This project analyzes subtitle dialogue from the TV show *Riverdale* using text mining and sentiment analysis techniques in R.

The goal was to explore:

- Word frequency patterns
- Sentiment trends
- Distinctive vocabulary
- Dialogue differences across episodes

## Tools Used

- R
- quanteda
- tidyverse
- ggplot2
- sentiment dictionaries

## Methods

- Parsed subtitle (.srt) files
- Cleaned and tokenized text
- Created document-feature matrices
- Performed sentiment analysis
- Generated visualizations

## Key Takeaways

This project demonstrated how text analysis can be applied to television dialogue to identify language trends and emotional tone across episodes.
